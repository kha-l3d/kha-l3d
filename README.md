I am a **Software Engineer** specializing in **Backend Development** within the **.NET Core ecosystem**. I focus on crafting secure, high-performance RESTful APIs, designing scalable relational databases, and writing clean, maintainable code following modern industry standards.

With a strong foundation in software engineering principles, I am passionate about solving complex system challenges, optimizing data retrieval, and delivering reliable backend architectures that power seamless digital experiences.
